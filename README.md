# Countdown 20. November

Schöne Countdown-App bis **20. November 12:00 Uhr**.

Als Progressive Web App (PWA) gebaut – lässt sich auf dem **Pixel 6** (und jedem Android-Gerät) zum Startbildschirm hinzufügen und sieht wie eine echte App aus.

## Live öffnen

Nach dem Aktivieren von GitHub Pages:

**https://zsenike.github.io/countdown-20-november/**

## Installation auf dem Pixel 6

1. Öffne die Seite im **Chrome**-Browser auf dem Handy.
2. Tippe oben rechts auf die **drei Punkte** → **„Zum Startbildschirm hinzufügen“** / **„App installieren“**.
3. Bestätige. Die App erscheint jetzt als Icon auf dem Homescreen.
4. Optional: Lange auf das Icon drücken → als Widget / Verknüpfung nutzen.

Die App läuft offline (dank Service Worker) und im Vollbildmodus (kein Browser-UI).

## Features

- Live-Countdown (Tage, Stunden, Minuten, Sekunden)
- Automatischer Jahreswechsel (nimmt nächstes Jahr, falls 20. Nov. schon vorbei)
- Konfetti-Effekt, wenn das Ziel erreicht ist
- Dark Glassmorphism Design
- Installierbar als PWA

## Lokal testen

Einfach `index.html` in einem modernen Browser öffnen oder einen lokalen Server starten:

```bash
npx serve .
```
